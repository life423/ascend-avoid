ASCEND AVOID — MAIN ICON FAVICON PACK

Converted from the approved V12 text-free app icon, without redesigning it.
Blue character and gold gem on the original navy background. No TEST ribbon.

FILES
favicon.ico — embedded 16, 32 and 48 pixel images for browser favicons.
favicon-16x16.png, favicon-32x32.png, favicon-48x48.png — PNG alternatives.
apple-touch-icon.png — 180 pixels for Apple home-screen bookmarks.
icon-192.png and icon-512.png — larger PNG assets for an existing web app manifest.
favicon-head.html — copy its link elements into your page's <head>.

INSTALL
Copy files into your site's public/root asset directory, then add the HTML link tags.
If hosted below a subpath, adjust the href paths accordingly.
For an existing manifest, reference the 192 and 512 pixel assets as purpose "any";
these are not maskable-specific artwork. This pack does not change your manifest.
Browsers cache favicons: a hard refresh or reopening the tab may be needed.

The navy background is intentionally preserved to match the approved app icon.
At 16 pixels, the character silhouette and gold gem remain the main recognition cues;
fine facial and gem details naturally reduce at that size.
